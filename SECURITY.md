# Security policy

onus is alpha software. Report a vulnerability privately through GitHub's
"Report a vulnerability" button on the Security tab of this repository, not in a
public issue. Expect an acknowledgement within a few working days.

Note that onus sends document and evidence text to the model provider you
configure (Anthropic by default). Do not run the model tier on material you
cannot share with that provider; `--no-llm` keeps everything local.
